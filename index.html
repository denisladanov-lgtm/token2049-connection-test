Google Sheets · проверка связи

Публичная оболочка без личных данных. Приватные события и заметки читаются только после вашего согласия в Google. Автоматический вход и фоновая синхронизация отсутствуют.

Подключение ещё не проверено на телефоне. Нужны OAuth web client, Google Picker API key и номер Google Cloud проекта, настроенные владельцем. Не вставляйте client secret.

1. Настройки владельца

Scope drive.file даёт API доступ к выбранным файлам целиком, включая запись. Приложение читает источник и пишет только в отдельную тестовую таблицу. Scope не ограничивается вкладками. Токен хранится только в памяти до закрытия / обновления страницы.

2. Выберите две разные таблицы

Файлы не выбраны

Для заметок выбирайте отдельную пустую тестовую таблицу с листом Sheet1. Запись идёт только в A3:E3: connectivity-browser-test. Реальные заметки в этом тесте не используются. Источник EVENTS не изменяется.

Результат

Ожидается настройка и согласие владельца.

Для повторной проверки в другой сессии или на Pixel заново авторизуйтесь, выберите те же файлы и нажмите «Перечитать». Сохранение конфигурации и вход в аккаунт выполняет владелец.
